# ParserGod

Контакты организаций с карт — в Excel. Выбираешь город и запрос, получаешь таблицу `.xlsx` с телефонами, сайтами, мессенджерами, адресами и рейтингом.

**Версия 1.0.1**

| Система | Файл |
|---|---|
| macOS · Apple Silicon (M1–M4), macOS 11+ | [ParserGod-mac-apple-silicon.dmg](ParserGod-mac-apple-silicon.dmg?raw=1) |
| macOS · Intel, macOS 11+ | [ParserGod-mac-intel.dmg](ParserGod-mac-intel.dmg?raw=1) |
| Windows 10 / 11 | [ParserGod-windows-setup.exe](ParserGod-windows-setup.exe?raw=1) |

## Первый запуск

- **Mac:** правый клик по программе → «Открыть» → «Открыть».
- **Windows:** если появится «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
- Нужен браузер Chrome, Edge, Яндекс.Браузер или Brave. На Windows Edge уже есть.

Ядро сбора — [parser-2gis](https://github.com/Eroloft/parser-2gis-new), лицензия LGPLv3; текст лицензии и уведомления лежат внутри установленной программы.
