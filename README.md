# ParserGod — сбор контактов организаций в Excel

Пользователь открывает программу, выбирает город, пишет запрос («кофейня», «автосервис») и отмечает нужные контакты. Программа собирает организации и сохраняет готовую таблицу `.xlsx` в «Документы/ParserGod».

Работает на Windows 10/11 и macOS 11+.

## Как это устроено

```
launcher.py            точка входа
app/                   ваш код (десктоп-обёртка)
  main.py              окно (pywebview: на Windows — WebView2/Edge, на Mac — WebKit)
  ui/index.html        интерфейс окна
  api.py               мост окно ↔ Python
  job.py               фоновый сбор: город × запрос → ядро → фильтры → Excel
  records.py           разбор ответа 2ГИС в строку таблицы, нормализация телефонов/ссылок
  excel.py             оформление .xlsx (шапка, ссылки, автофильтр)
  browsers.py          поиск Chrome / Edge / Яндекс.Браузера / Brave
  brand.py             НАЗВАНИЕ, ВЕРСИЯ, контакт поддержки — меняйте здесь
  selftest.py          самопроверка сборки (--selftest, --selftest --live)
parser_2gis/           ядро из github.com/Eroloft/parser-2gis-new (LGPLv3)
ParserGod.spec        конфиг PyInstaller
installer.iss          установщик Windows (Inno Setup)
build_windows.bat      сборка под Windows одним кликом
build_mac.sh           сборка .app/.dmg на Mac
.github/workflows/     автосборка Windows + Mac на GitHub
```

Ядро запускает браузер в скрытом режиме и открывает `2gis.ru/<город>/search/<запрос>`. Затем оно по очереди кликает карточки и перехватывает JSON-ответы API каталога. Для 2ГИС это выглядит как обычный пользователь. Поэтому на компьютере клиента нужен браузер на движке Chromium. На Windows почти всегда есть Edge, так что ставить ничего не придётся.

## Запуск из исходников (для разработки)

- Windows: дважды кликнуть `run_dev.bat`. Нужен Python 3.12 с python.org.
- Mac: `bash run_dev.sh`.

Флаг `--debug` открывает инструменты разработчика в окне.

## Сборка программы для продажи

### Windows — у себя на компьютере
1. Установите [Python 3.12](https://www.python.org/downloads/) и отметьте галочку «Add python.exe to PATH».
2. Необязательно: установите [Inno Setup 6](https://jrsoftware.org/isdl.php), чтобы получился установщик, а не zip-архив.
3. Дважды кликните `build_windows.bat`.
4. Результат появится в папке `release\`: `ParserGod-Setup-1.0.0.exe` или `ParserGod-windows.zip`.

### macOS — через GitHub (Mac не нужен)
1. Создайте приватный репозиторий на GitHub и загрузите в него эту папку.
2. На вкладке **Actions → Build → Run workflow** запустите сборку. Через 10–15 минут в артефактах будут:
   - Windows-установщик и portable-zip;
   - `.dmg` для Mac на Apple Silicon (M1–M4);
   - `.dmg` для Mac на Intel.
3. Если сделать push тега `v1.0.1`, сборка ещё и создаст черновик релиза со всеми файлами.

Если у вас есть Mac, можно собрать на нём командой `bash build_mac.sh`.

### Проверка готовой сборки
`ParserGod.exe --selftest --live` делает 3 реальных запроса «аптека» в Москве. Отчёт сохраняется в `%LOCALAPPDATA%\ParserGod\selftest.txt` (на Mac — `~/Library/Application Support/ParserGod/selftest.txt`).

## Перед продажей

- **Название и иконка.** Название меняется в `app/brand.py`, и ещё в двух местах: `#define MyAppName` в `installer.iss` и `<title>` в `ui/index.html`. Иконка лежит в `assets/` (`icon.png`, `.ico`, `.icns`), сейчас там заглушка. Не используйте в названии и логотипе «2ГИС»: это чужой товарный знак.
- **Предупреждения при запуске.** Windows SmartScreen покажет «Windows защитила ваш компьютер», клиент нажимает «Подробнее → Выполнить в любом случае». На Mac при первом запуске нужно открыть программу через правый клик → «Открыть». Убрать эти предупреждения можно только подписью: сертификат для Windows и Apple Developer ID за $99 в год. Для Mac в `build_mac.sh` уже есть заготовка `SIGN_ID`.
- **Лицензия ядра (LGPLv3).** Продавать программу можно. Условия такие: в поставке остаются `LICENSE-LGPL.txt` и `NOTICE.txt` (сборка кладёт их автоматически), ядро лежит открытыми `.py`-файлами и заменяется пользователем (так уже настроено в `.spec`), а исходники ваших изменений ядра доступны (форк на GitHub). Код в `app/` остаётся вашим и может быть закрытым.
- **Условия 2ГИС.** Пользовательское соглашение 2ГИС запрещает автоматический сбор данных. Риск блокировок и претензий несёт тот, кто парсит, а частично и продавец инструмента. Контакты ИП могут считаться персональными данными (152-ФЗ). Это стоит учесть в оферте и в том, как вы рекламируете продукт.
- **Защита от копирования.** Сейчас её нет: купленный файл можно переслать. Следующий шаг — активация по ключу через сервер, например на Supabase.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Не найден браузер» | Установить Google Chrome или указать путь к браузеру в «Дополнительно» |
| 0 результатов, таймауты | Включить «Показывать браузер» и/или паузу 300–500 мс между карточками |
| Окно белое на Windows | Обновить [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) |
| Нужна диагностика | Кнопка «Журнал» в окне; `ParserGod --selftest --live` |
